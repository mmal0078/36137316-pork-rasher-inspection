Pork rasher packaging inspection

MMA3001 project: detecting packaging and meat-placement defects in conveyor images with a fine-tuned YOLOv8n detector.

  • API documentation: every module and function of the porkinspect package, generated by pdoc from the docstrings
  • Command-line scripts (the pipeline, run in this order):
    • prepare_data.py: data audit and YOLO export
    • train_yolo.py: fine-tune YOLOv8 and save raw predictions (run on a GPU)
    • analyse_run.py: threshold choice, frame-level results and failure cases
    • baseline.py: hand-crafted features + decision tree / SVM / MLP
    • compare.py: detector vs baseline, with paired bootstrap and McNemar test
    • compare_runs.py: sensitivity runs (image size, model size)
    • brightness_test.py: robustness to brightness changes
    • profile_pipeline.py: cProfile, arithmetic intensity and roofline
    • inspect_image.py: run the trained model on one image
    • build_docs.py: rebuild this site
  • Test report: latest pytest run (33 passed in 1.84s)
  • Source code on GitHub, with the README, results and notebooks
